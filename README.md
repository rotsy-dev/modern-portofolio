## 🧭 À propos

Ce portfolio présente mes projets, mon expérience et mes compétences en développement web et mobile. Il met en avant mon travail sur des stacks variées — Symfony/PHP côté backend, Flutter pour le mobile, et React/Next.js pour des interfaces modernes et interactives.

## ✨ Fonctionnalités

- 🎨 Interface moderne avec animations fluides (Framer Motion)
- ✨ Effets de particules interactifs (TSParticles)
- 📱 Design responsive (mobile / tablette / desktop)
- ⚡ Performances optimisées grâce à Next.js
- 🌙 Sections projets, compétences et parcours

## 🛠 Stack technique

| Catégorie   | Technologies |
|-------------|--------------|
| Framework   | Next.js, React |
| Style       | Tailwind CSS |
| Animations  | Framer Motion |
| Effets      | TSParticles |
| Langage     | TypeScript |

## ⚙️ Installation

```bash
git clone https://github.com/rotsy-dev/modern-portofolio.git
cd modern-portofolio
npm install
npm run dev
```

Puis ouvrir [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## 📜 Scripts disponibles

| Commande         | Description                          |
|------------------|---------------------------------------|
| `npm run dev`    | Lance le serveur de développement     |
| `npm run build`  | Compile le projet pour la production  |
| `npm run start`  | Démarre le serveur en mode production |
| `npm run lint`   | Vérifie le code avec ESLint           |
| `npm run lint:fix` | Corrige automatiquement le lint     |

## 📂 Structure du projet

```
modern-portofolio/
├── app/              # Pages et routes (App Router)
├── components/       # Composants réutilisables
├── public/           # Assets statiques (images, icônes...)
├── styles/           # Fichiers de style globaux
└── package.json
```

## 🚀 Déploiement

Ce projet est prêt à être déployé sur [Vercel](https://vercel.com/) :

```bash
npm run build
```

Ou en un clic via le bouton Vercel une fois le repo connecté à votre compte.
