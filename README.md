## À propos

Ce portfolio présente mes projets, mon expérience et mes compétences en développement web et mobile.

## Stack technique

- Next.js
- React
- Tailwind CSS
- Framer Motion
- TSParticles

## Lancer le projet en local

```bash
npm install
npm run dev
```

Puis ouvrir [http://localhost:3000](http://localhost:3000).
